# BOA — Build On Arc

Community builder-meme site for Circle's Arc chain. Independent project
inspired by builder culture — not affiliated with BOB, BNB Chain, or Arc.

Static site: `index.html` / `style.css` / `script.js`, no build step.
Deploy as-is on Vercel/Netlify/GitHub Pages, or open `index.html` directly.

`images/hero.jpg` — the hero banner. `$BOA`'s contract address isn't
live yet; the Token section shows "Coming soon" until it's wired in.
